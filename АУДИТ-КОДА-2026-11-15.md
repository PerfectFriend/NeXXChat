# NeXX — аудит кода и устранение находок внешних аудиторов (2026-11-15, вечер)

Объект: `~/Projects/NeXX` (ветка master). База проверки: `cargo test --release`
(76 unit + 7 негативных C1), живые интероп-прогоны против `smp6.simplex.im:5223`
(5/5 PASS), сборка Android (3 ABI), `strings` по релизным `.so`.

## 0. Откуда находки

Два независимых аудита (аудитор №2 — Claude; Grok сверялся с отчётом №2 по
подсказке) дали пересекающийся список. Каждая находка перепроверена по коду
в этом репозитории; в таблицах ниже отмечено, что подтверждено лично.

## 1. Статус находок (после спринта 1–3)

| ID | Находка | Статус | Где закрыто |

## 2. Негативные тесты C1 (приёмочная таблица аудита)

`rustcore/tests/audit_c1_pinning.rs` — 7 тестов, все зелёные:

1. self-signed leaf с CN хоста → **reject**
2. чужой leaf + настоящий CA в цепочке → **reject** (проверяется подпись, а не any-match)
3. неверный expected keyHash → **reject**
4. пустой/некорректный pinning → **reject**
5. SMP-hello chain ≠ TLS chain → **reject**
6. `session_id` ≠ TLS Finished → **reject**
7. корректность constant-time сравнения

## 3. Что реально сделано хорошо (подтверждено прогонами)

- Крипто-стек: HSalsa20 pre-layer, `crypto_box` tag‖ct, KAT против эталонов simplexmq.
- TLS к публичным релеям: Ed448 в ClientHello, `openssl`-бэкенд (ring не умеет ed448).
- SMP wire + команды очередей, agent-протокол (все 8 AMsgType), ротация очередей.
- XFTP v3/v4 (64 КБ roundtrip), INV-ссылка (`connreq.rs`, `invite_flow`).
- Живые интеропы: **5/5 PASS** (chat_flow, agent_smoke, agent_rotate, smp_cmds, invite_flow).

## 4. Классификация (broken / dead / unbuilt)

- **Broken:** нет — все известные критичные и high-находки закрыты регрессиями.
- **Dead:** INV/ADR/QKEY — в коде, но не в боевом UI-цикле; прокси control plane (`control.rs`) без рантайма.
- **Unbuilt:** PQ ratchet, XRCP, групповые чаты, multi-hop routing, chunk-XFTP >64 КБ, reconnect/backoff (M3), сервер-конфиг (M6), opaque-handle API сида (H7).

## 5. Готовность к повторному аудиту

**Готово к проверке:** C1 (6 негативных тестов), C2 (strings-приёмка), H1–H5, H8, M1, M2, M4 (частично), M5 (частично).

**Честно не сделано:** H6 (JNI KDF-параметры), H7 (opaque-handle API сида), M3, M6–M11 — это следующий спринт, а не «готово».
