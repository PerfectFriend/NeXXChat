# ПИСЬМО АУДИТОРАМ — NeXX (Rust-ядро + Android)

Дата: 2026-11-15. Ветка: `master`, HEAD на момент написания — см. `git log -1`.

## Что это
NeXX — мессенджер на Rust с полной совместимостью протоколов SimpleX
(SMP v20, агент-протокол, XFTP v3 — частично). Цель аудита: протокольное ядро,
crypto, JNI-граница, клавиатура.

## С чего начать (5 минут)
1. `АУДИТ-КОДА-2026-11-15.md` — находки, классификация broken/dead/unbuilt, чек-лист.
2. `АУДИТ-ГОТОВНОСТИ.md` — процент готовности по слоям и что закрыто.
3. Воспроизводимость одной командой:
   ```
   cd rustcore && bash scripts/interop-all.sh smp6.simplex.im:5223
   ```
   Ожидается: PASS chat_flow / agent_smoke / agent_rotate / smp_cmds / invite_flow / unit.
   Требуется `NEXX_TLS=openssl` (выставляет сам скрипт) и CA-цепочка
   `~/.hermes/cache/scratch/smp6-5223-chain.pem` (скачать:
   `openssl s_client -connect smp6.simplex.im:5223 -showcerts </dev/null | awk '/BEGIN CERT/,/END CERT/' > <путь>`).
4. `cargo test --release --lib` — 71/71 (KAT crypto_box, serviceSig, roundtrip connReq).

## Зоны повышенного внимания (границы доверия)
- `rustcore/src/jni_smp.rs` — JNI-граница: все ключи приходят из Kotlin keytree, хардкода нет (был баг — закрыт), read timeout 300 мс (был баг блокировки 60 с через `Box<dyn TlsIo>` — закрыт регрессией `OK NONBLOCK poll` в chat_flow).
- `rustcore/src/protocols/smp.rs` + `smp_client.rs` — ручная реконструкция crypto (crypto_box, HSalsa20, HKDF, Ed448-верификация). Закрыта KAT-тестами против эталонов. Ed448 SPKI-префикс 58 байт, `Verifier::new_without_digest`.
- `rustcore/src/protocols/connreq.rs` — connReqData по spec; URI `nexx://link#/<b64url>`.
- Клавиатура: `app-rust/.../SecureTextField.kt` + `StandardKeyboard` — без IME/Accessibility сервисов; доказательство: `aapt dump xmltree --file AndroidManifest.xml NeXX-*-debug.apk | grep -i "input_method\|accessibility"` → пусто. Privacy-аудит: `~/Projects/MatrixKeyboard/docs/PRIVACY-AUDIT.md`.

## Честно заявленные ограничения (unbuilt, не дефекты)
- Полная подписанная ссылка SimpleX (Ed25519 fixedData + PQ ratchet X448/sntrup761) — не реализована; инвайты сейчас NeXX-to-NeXX.
- XRCP, группы, multi-hop, chunk-XFTP — не реализованы.
- XFTP v3 против публичных релеев — гипотеза, требует проверки HTTP/2+ed448.
- Рантайм JNI на устройстве не прогонялся (нет эмулятора в момент аудита); компиляция и манифест проверены.

## Как прогонять живые интеропы вручную
```
cd rustcore
cargo build --release --bin chat_flow --bin agent_smoke --bin agent_rotate --bin smp_cmds --bin invite_flow
export NEXX_TLS=openssl
B=/home/thomas/build/cache/cargo-target/release
$B/chat_flow   smp6.simplex.im:5223   # CHAT UI FLOW OK + NONBLOCK poll
$B/agent_smoke smp6.simplex.im:5223 <ca.pem>  # AGENT INTEROP OK
$B/agent_rotate smp6.simplex.im:5223 <ca.pem> # ROTATE INTEROP OK
$B/smp_cmds    smp6.simplex.im:5223 <ca.pem>  # SMP CMDS INTEROP OK
$B/invite_flow smp6.simplex.im:5223   # INVITE FLOW OK (1-1 в обе стороны)
```
